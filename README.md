# Using BitLocker

BitLocker is a full-disk encryption feature provided by Microsoft for Windows operating systems. It safeguards data by encrypting entire drives, including the system partition, and can be applied to both internal and external drives. It ensures that if a device is lost or stolen, the data remains inaccessible to unauthorized users, providing a critical layer of security for sensitive information.

## Instructions
## Part A: Using BitLocker
Access BitLocker Drive Encryption, turn on BitLocker for New Volume (E:), save the recovery key in the Documents folder, and encrypt it.

### STREP 1
Right-cli8ck the Start menu and select Search.

### STEP 2
Type (Manage bitlocker) and click Manage BitLocker to open the BitLocker Drive Encryption window.

### STEP 3
Click New Volume(E:) BitLocker off.

### STEP 4
Under New Volume (E:) BitLocker off, click the Turn on BitLocker link.

### STEP 5
In the BitLocker Drive Encryption (E:) dialog box, check the Use a password to unlock the drive checkbox.

### STEP 6
In the Enter your password and Reenter your password text boxes, type ucertify and click Next.

### STEP 7
Click Save to a file to back up your recovery key.

### STEP 8
In the Save BitLocker recovery key as dialog box, in the left pane, click Documents and then click the Save button to recovery key with the default name.

### STEP 9
Click NEXT twice

### STEP 10
Verify that the Compatible mode (best for drives that can be moved from this device) radio button is selected by default, and then click Next.

### STEP 11
Click Start encrypting

### STEP 12
At the BitLocker Drive Encryption prompt, click Close.

### STEP 13
Close all windows.
